1. Start the program.
2. Create a HashMap to store account numbers and balances.
3. Display the banking menu.
4. Get the user's choice.
5. If the user selects Create Account:
   a. Enter account number.
   b. Enter initial balance.
   c. Store the account number and balance in HashMap.
6. If the user selects Deposit:
   a. Enter account number.
   b. Enter deposit amount.
   c. Add the amount to the account balance.
7. If the user selects Withdraw:
   a. Enter account number.
   b. Enter withdrawal amount.
   c. Check the available balance.
   d. Deduct the amount if sufficient balance is available.
8. If the user selects Check Balance:
   a. Enter account number.
   b. Display the account balance.
9. If the user selects Exit:
   a. Stop the program.
10. Repeat the above steps until the user selects Exit.
11. Stop the program.
